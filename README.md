# Portfólio — Igor Campos

Portfólio pessoal estático desenvolvido com HTML, CSS e JavaScript puro.

## Recursos

- Layout responsivo para desktop e dispositivos móveis
- Temas claro e escuro com preferência salva no navegador
- Navegação acessível com destaque da seção atual
- Formulário que inicia uma conversa pelo WhatsApp
- Animações sutis com suporte a `prefers-reduced-motion`

## Executar localmente

```powershell
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
